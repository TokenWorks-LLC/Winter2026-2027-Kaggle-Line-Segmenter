# Documentation

- [line_segmentation/line_model.md](line_segmentation/line_model.md): the report on the line model. It covers the
  data and ground truth, the model and its training, the read-out from maps to lines and crops, how it is evaluated,
  the results of every run and the comparison with other line finders. Appendix A is the experiment log in order.
- [line_segmentation/related_work.md](line_segmentation/related_work.md): other line finders compared with the line
  model (Kraken retrained, the Dencker et al. line network rebuilt) and the literature review behind the approach.
- [line_segmentation/data_cdli_artifacts_json.md](line_segmentation/data_cdli_artifacts_json.md): notes on the CDLI
  catalogue dump used for transliterations and museum numbers.
- [../examples/line_signs_std_sample/README.md](../examples/line_signs_std_sample/README.md): the description of the
  `line_signs_std` dataset.
- [../line_segmentation/segment/README.md](../line_segmentation/segment/README.md): running a finished model on new images.
